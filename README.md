# Sloppy Pals: Rage Brawl

A finished static browser brawler: three Sloppy Pals plus a Human Commander, fighting on a speed timeline instead of turns.

Play it at https://crsyndrome-tech.github.io/sloppy-pals/

## Play locally

Serve the repo root over HTTP (opening `index.html` as a file can block the scripts), then open the printed address in a browser:

```bash
python3 -m http.server 8080
```

Full rules are in [RULES.md](RULES.md).
